# german-grammar
Website to learn and practice German.

The main page is a menu leading to three sections:

- **Grammar** (`grammar/`) – reference guide for German grammar rules
- **Verbs** (`verbs/`) – practice German verbs (conjugations, meanings, cases)
- **Nouns** (`nouns/`) – practice German nouns and their articles

Shared assets (favicons, icons) live in the repository root and `icons/`.
